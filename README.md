# 📊 Sales Data Analysis Dashboard (Power BI)

### 🔍 Project Overview
This project is an **Interactive Sales Data Analysis Dashboard** built using **Microsoft Power BI**.  
The dashboard provides valuable business insights into total sales, transactions, quantities, ratings, and payment trends for various mobile brands such as Apple, Samsung, Vivo, OnePlus, and Xiaomi.

---

### 🎯 Objectives
- Analyze total sales performance by brand, city, and mobile model.  
- Visualize monthly and daily sales trends.  
- Track customer ratings and satisfaction levels.  
- Understand the distribution of transactions across different payment methods.  
- Provide key insights for data-driven business decisions.

---

### 📈 Key Insights
- **Total Quantity Sold:** 19K  
- **Total Sales:** ₹769M  
- **Total Transactions:** 4K  
- **Average Sales per Transaction:** ₹40K  

#### 🔹 Insights by Visuals:
- **Sales by City Map:** Shows geographical distribution of sales across India.  
- **Monthly Sales Trend:** Peak sales observed during July.  
- **Top Performing Brands:** Apple, OnePlus, Samsung dominate in total sales and quantity.  
- **Payment Analysis:** UPI and Debit Cards are the most used payment methods.  
- **Customer Ratings:** Majority of customers rated 5 stars.

---

### 🧰 Tools & Technologies Used
- **Power BI** – for building the interactive dashboard  
- **Microsoft Excel / CSV** – for data preprocessing  
- **SQL / MySQL (optional)** – for backend data handling and queries  
- **DAX Functions** – for calculations and measures in Power BI  

---

### 📂 Dashboard Features
- Interactive filters by **Brand**, **Payment Method**, and **Month**  
- Drill-through capabilities for deeper insights  
- Dynamic KPI cards and charts  
- Geo-spatial map for sales by city
